## Voice

Write clear, friendly technical English for learners with calculus knowledge.
Preserve the source’s intuition-first teaching style; prefer a short direct
sentence over a literal construction. Keep model names, dataset names, API
names, commands, citations, formulas, filenames, URLs, anchors, and MyST roles
unchanged.
